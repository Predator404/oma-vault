# Vault — reference (`reference/`)

Vault tooling and third-party library/plugin reference, plus verbatim doc
mirrors. Not owned by any single entity — shared reference material.

## Contents

- [`obsidian/vault-conventions.md`](obsidian/vault-conventions.md) — **canonical
  rules for how notes are created in this vault** (areas, folder templates, how
  to write notes programmatically).
- [`obsidian/templater/`](obsidian/templater/index.md) — verbatim mirror of the
  **Templater** plugin docs (tag 2.25.0) + a repo pointer. Upstream:
  <https://github.com/SilentVoid13/Templater>.

## Note conventions

New notes in this area use the **`Templates/Reference Doc.md`** folder template
(auto-applied by Templater on empty-note creation). The `obsidian/templater/`
mirror is copied-in verbatim and excluded from templating. See
[`AGENTS.md`](../AGENTS.md) and
[`obsidian/vault-conventions.md`](obsidian/vault-conventions.md).
