# Vault — agent sections (`agents/`)

Per-agent working notes (WS4). One subtree per agent entity
(`agents/<name>/`), matching the entity's C1 `vaultSection`.

> The agent's C1 **record** (system prompt + metadata) lives in the registry at
> `registry/entities/<name>.md`, **not** here. This area holds the agent's
> *notes*, not its definition.

## Note conventions

New notes in this area use the **`Templates/Agent Note.md`** folder template
(auto-applied by Templater on empty-note creation). When writing notes
programmatically, seed from that template. See the vault-wide rules in
[`AGENTS.md`](../AGENTS.md) and
[`reference/obsidian/vault-conventions.md`](../reference/obsidian/vault-conventions.md).
